# Unemployment Analysis with Python

Internship Project

## About the Project

This project analyzes unemployment trends in India using Python and data visualization techniques.

## Objectives

- Analyze unemployment rates across Indian regions.
- Compare rural and urban unemployment.
- Study monthly unemployment trends.
- Visualize unemployment data.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure

- "data/" – Raw and processed datasets
- "notebooks/" – Jupyter Notebook analysis
- "src/" – Python source code
- "outputs/figures/" – Generated graphs
- "outputs/tables/" – Analysis summary tables
- "reports/" – Project reports
- "docs/" – Documentation

## Key Findings

The historical dataset analysis found differences in unemployment rates across regions and between rural and urban areas.

## How to Run

1. Install the required libraries.
2. Open the Jupyter Notebook.
3. Run the notebook cells in order.

## Note

The datasets used in this project contain historical data ending in 2020. Results should not be interpreted as current unemployment figures.
